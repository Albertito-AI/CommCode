# Project context

CommCode is Albert Tan's requested standalone repository number 13. The owner
selected the name CommCode on 2 November 2026. The mandate is an independently
implemented public-interest platform that moves ideas towards useful, inspectable,
portable software. User ownership, privacy, education and forkability guide decisions.

The immediate engineering objective is a verified single-operator vertical slice.
The broader mandate is a roadmap, not a claim that every requested feature exists.
See README, VERIFICATION, KNOWN_ISSUES and ROADMAP before making capability claims.
