# Project naming record

On 2 November 2026 the owner expressly selected **CommCode**, replacing the initial
provisional codename Praxisweave. Repository spelling: `CommCode`; npm package and
runtime prefix: `commcode`.

A public web search for CommCode software/GitHub found existing uses, including
Commerce Codeworks at https://commcode.com/about_us.html and
https://commcode.com/successes.html. There are also unrelated commodity-code and
community-code references. This is an obvious naming conflict record, not a legal
trademark clearance opinion. No registry-wide search or domain purchase occurred.
The chosen name is retained under the owner's instruction. Avoid suggesting any
affiliation with existing businesses. Revisit naming before a formal brand launch.
