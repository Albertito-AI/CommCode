# Community expense tracker

A dependency-free starter. Run `node server.mjs`, then visit `http://localhost:8080`.
Run `node --test` to verify the amount calculations and input validation.
The server reads `HOST` and `PORT` for portable previews. Data is held in browser
memory and lost on refresh. Export JSON before closing; add persistence if needed.
